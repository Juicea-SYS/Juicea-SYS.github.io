# Glossaire

| Terme | Définition rapide |
|---|---|
| **ACC** (accumulateur) | Registre principal de calcul du CPU. |
| **ALU** | *Arithmetic Logic Unit* — circuit combinatoire qui effectue les calculs (addition, soustraction...). |
| **Bascule (flip-flop / latch)** | Circuit séquentiel élémentaire capable de mémoriser un bit. |
| **Bus** | Ensemble de fils partagés transportant une donnée entre plusieurs composants. |
| **Circuit combinatoire** | Circuit dont la sortie ne dépend que des entrées actuelles. |
| **Circuit séquentiel** | Circuit dont la sortie dépend aussi de l'état interne / passé. |
| **Complément à deux** | Représentation binaire standard des nombres signés. |
| **Décodeur** | Circuit qui active une seule sortie parmi `2ⁿ`, selon une entrée de `n` bits. |
| **Drapeau (flag)** | Bit indiquant une propriété d'un résultat (zero, carry...). |
| **Front (montant / descendant)** | Transition d'un signal de 0 vers 1 (montant) ou de 1 vers 0 (descendant). |
| **Fetch / Decode / Execute** | Les trois phases du cycle d'exécution d'une instruction. |
| **IR** (registre d'instruction) | Registre contenant l'instruction en cours de traitement. |
| **ISA** | *Instruction Set Architecture* — le jeu d'instructions d'un processeur. |
| **MAR** | *Memory Address Register* — registre contenant l'adresse mémoire en cours d'accès. |
| **Multiplexeur (mux)** | Circuit qui sélectionne une entrée parmi plusieurs pour l'envoyer en sortie. |
| **NAND universelle** | Propriété de la porte NAND permettant de construire toute fonction booléenne. |
| **Opcode** | Partie d'une instruction qui code l'opération à effectuer. |
| **PC** (compteur ordinal) | Registre contenant l'adresse de la prochaine instruction à exécuter. |
| **RAM** | Mémoire vive, lisible et modifiable, adressable par position. |
| **Registre** | Petite mémoire, généralement de la taille d'un mot machine (ici 8 bits). |
| **Ripple-carry adder** | Additionneur multi-bits où la retenue se propage bit par bit. |
| **Tri-state (trois états)** | Sortie pouvant être à 0, à 1, ou déconnectée (haute impédance). |
| **Von Neumann (architecture)** | Modèle où instructions et données partagent la même mémoire. |
