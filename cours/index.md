# Cours 1 — De la porte logique au CPU

Treize chapitres, du transistor logique au CPU complet (et son ouverture vers
le 64 bits, les architectures comparées et le GPU). Chaque chapitre suit le
même format :

- **🎯 Objectifs** — ce que tu dois savoir faire à la fin.
- **📚 Théorie** — le cours à proprement parler.
- **🛠️ Dans Digital Logic Sim** — comment le chapitre se traduit dans l'outil.
- **✏️ Exercices** — la spécification à respecter, sans solution.
- **🤔 Questions de réflexion** — pour vérifier que tu as compris le "pourquoi".
- **🚀 Pour aller plus loin** — extensions facultatives.

Avance dans l'ordre : chaque chapitre réutilise les circuits du précédent.
